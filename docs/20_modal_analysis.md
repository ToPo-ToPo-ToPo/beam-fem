# 線形モーダル解析

`beamfem.modal` は、線形化した梁・トラス・シェル混在モデルの非減衰固有値問題

$$
K\phi = \omega^2 M\phi
$$

を解く。部材質量は節点の並進自由度へ集中質量として配分し、回転質量を持たない自由度は静的縮約してから一般化固有値問題を解く。

`solve_modal(model, n_modes=...)` は固有角振動数、固有振動数、質量正規化モード形を返す。ゼロ・負の固有値や剛体モードは診断付きで除外される。

## 適用範囲

- 微小変形、線形弾性、非減衰の自由振動
- 部材分布質量を節点へ集中させる近似
- 解析モデルの拘束後に残る弾性モード

応答スペクトル、時刻歴応答、減衰、質量整合行列、幾何剛性による固有値座屈はこのAPIの対象外である。
